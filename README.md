# Membership & Loyalty Points

ระบบ Membership & Loyalty Points

## Tech Stack

- **Backend**: Node.js + Express + Prisma + PostgreSQL + TypeScript
- **Frontend**: Next.js + shadcn/ui + Recharts + Three.js + TypeScript
- **Mobile**: React Native Expo + NativeWind + Reanimated + Lottie + Skia + TypeScript

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Mobile
```bash
cd mobile
npm install
npx expo start
```
